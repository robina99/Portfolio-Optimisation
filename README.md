# Portfolio-Optimisation
This project explores the use of Genetic Algorithms (GA) for portfolio optimization and asset selection in financial markets. The study applies evolutionary optimization techniques to maximize risk-adjusted returns using historical stock market data from Yahoo Finance.

The project investigates:

Portfolio weight optimization using Genetic Algorithms
Comparison with random and equally weighted portfolios
Multi-objective optimization balancing risk and return
Automated asset selection from a larger stock universe
Integrated two-stage Genetic Algorithm optimization

The portfolio optimization process aims to maximize the Sharpe Ratio while maintaining manageable portfolio risk.
